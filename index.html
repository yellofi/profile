AI R&D에 접근하는 방식

잘 푸는 AI, 잘 만든 문제집.

데이터셋은 AI가 풀어야 할 문제집입니다. 실제로 마주칠 다양한 사례와 합의된 정답 기준을 담고, 베이스라인의 성능과 실패를 살피며 문제집과 AI를 함께 고도화합니다. 그 과정에서 어떤 문제를 잘 풀어야 하는지, 데이터와 학습 문제를 보완할지, 기술 자체의 한계를 넘어야 할지를 구분합니다.

01

풀어야 할 문제를 담다

실제 사례를 담고 애매한 정답 기준을 합의해, AI가 잘해야 할 문제와 평가 기준을 구체화합니다.

02

오답에서 다음 개선을 찾다

베이스라인의 성능 추이와 실패 사례를 분석해, 문제집의 빈틈과 모델·알고리즘의 한계를 구분합니다.

03

문제집과 AI를 함께 고도화하다

라벨링 도구와 학습 목표를 설계하고, 모델·파이프라인을 개선하거나 재설계한 뒤 전체 결과로 검증합니다.

Data-centric 개발에서 바이오마커 범용 분석 아키텍처로.

초기 종양 분할에서 Model-centric 접근만으로 유의미한 개선을 얻지 못한 뒤, 실패 사례와 라벨 기준을 깊이 탐구하는 Data-centric 개발로 성능을 확보했습니다. 이후 바이오마커 범용 분석을 위한 통합 세포 구성요소 모델 아키텍처를 직접 설계하고 전체 시스템의 고도화를 주도했습니다.

Data-centric 개발 → 범용 통합 아키텍처 → 전체 시스템 고도화

시행착오와 판단 과정 보기

01 · Data-centric 접근으로 초기 성능 확보

초기 종양 분할 모델 개발에서 분할 모델 경량화, 다중 입력 모델 아키텍처, 염색 증강 기반 Semi-supervised Learning 등 Model-centric 접근을 시도했지만, 당시에는 유의미한 성능 개선으로 이어지지 않았습니다. 이후 성능이 떨어지는 사례를 분석하고 해당 사례의 훈련 데이터를 보강하며, 애매한 어노테이션 기준을 합의하는 Data-centric 방법들을 적용했습니다. 이를 통해 AI가 잘해야 할 문제를 깊이 탐구하고 실질적인 성능 개선을 이끌어냈습니다.

02 · 도구와 품질 관리된 데이터셋 구축

직접 상당량의 세포 어노테이션을 수행하고 Active Learning 관점의 데이터 샘플링을 적용했습니다. SAM 기반 조직·세포 라벨링 도구를 자발적으로 개발·배포해 팀의 데이터셋 구축에 활용했습니다. 정답 기준을 합의하고 지속적으로 품질을 검수한 세포 데이터셋이 갖춰진 뒤에는 SOTA 기반 모델 구조와 새로운 인스턴스 분리 알고리즘의 도입으로 큰 성능 향상을 얻었습니다. 세포 데이터셋 구축 과정에서는 noisy/hard sample을 구분하고 Curriculum Learning으로 성능을 안정화했습니다. 개발 단계에 따라 효과적인 개선 수단이 달라진다는 경험이었습니다.

03 · 바이오마커 범용 분석을 위한 통합 아키텍처 설계

Fully Quantitative 세포막 분석에는 고정된 세포 분류 대신 염색 강도와 발현 완전성을 계측하는 구조가 필요했습니다. 염색된 세포막의 직접 어노테이션이 비현실적이라는 feasibility test 결과를 바탕으로, 세포·세포핵 인스턴스 라벨을 구성요소 Pseudo Label로 가공했습니다. 이를 이용해 핵·세포질·세포막을 함께 식별하는 Universal Cellular Compartment Segmentation을 직접 설계하고, 바이오마커 범용 세포 분석을 위한 통합 모델 아키텍처로 발전시켰습니다. 구조적 식별과 연속적 염색 계측을 바이오마커별 판독 기준에서 분리한 설계입니다. 별도로 Edge Filter 기반 Pseudo Label을 활용해 조직 전경 식별을 딥러닝으로 전환하는 PoC도 진행했습니다.

04 · 전체 시스템의 개선 우선순위를 결정

개별 모델의 성능과 전체 계측 파이프라인의 성능을 구분해 평가했습니다. PD-L1에서는 정규화된 세포막 염색 계측값에 임계치를 적용해 암세포의 양성·음성을 구분하고 TPS를 계산했습니다. 외부 병원 데이터에서 의사 판독과의 불일치 사례를 분석하며, 1년 넘게 데이터·모델·처리 알고리즘 전반의 개선 우선순위를 스스로 결정해 목표 수준의 일치도를 확보했습니다. 초기 탐색적 프로토타이핑으로 계측 접근을 구체화했고, Computational Pathology와 IHC 세미나를 자발적으로 진행하며 전체 시스템과 기술 방향에 대한 이해도 넓혔습니다.

계측 성능의 병목에서 공통 R&D 기반으로.

각도 일치도를 기준으로 계측 아키텍처와 학습 목표를 재설계했습니다. 딥바이오의 Curriculum Learning 경험을 계승해 confidence 기반 샘플 선별, 중앙 서버 라벨링 도구, 2차 학습으로 최종 성능을 최적화했습니다. 이와 함께 공통 VFM 아키텍처 연구를 제안·주도하고 벤치마크와 평가 체계를 구축했습니다.

Task 재설계 → Confidence 기반 라벨링 → Curriculum Learning → 공통 역량

시행착오와 판단 과정 보기

01 · 최종 계측 목표에서 출발

최종 목표는 척추·골반 각도 측정의 일치도였습니다. 기존 파이프라인은 척추·골반 분할, 척추별 랜드마크 탐지, 각도 계산으로 구성됐습니다. 이 구조 안에서의 개선만으로 목표 성능 확보가 어려워지자, 예측 아키텍처와 학습 목표가 최종 계측 오차에 얼마나 직접적으로 연결되는지 다시 검토했습니다.

02 · 학습 문제를 최종 오차에 정렬

각도 오차에 정렬된 방향을 예측하고 그 결과에서 각도를 계산하는 DINOv3 기반 단일 모델을 설계했습니다. 중간 Task의 연쇄에 의존하던 구조에서, 원하는 계측 결과와 학습을 더 직접적으로 연결했습니다.

03 · 데이터·학습 전략을 계승해 최종 성능 최적화

딥바이오에서 noisy/hard sample을 구분하고 Curriculum Learning으로 성능을 안정화한 경험을 계승했습니다. Landmark (anchor) confidence를 기반으로 noisy/hard sample을 선별하고, keypoint labeling tool을 직접 개발해 중앙 서버에 배포했습니다. 이를 통해 약 1,000건의 레이블을 빠르게 확보하고 Curriculum Learning 관점의 2차 학습으로 최종 계측 성능을 최적화했습니다. 실패 사례 분석·집중 라벨링·단계적 학습을 하나의 개선 사이클로 연결한 과정입니다.

04 · 실험을 비교 가능한 체계로

근골격계 X-ray Task를 위한 VFM 기반 공통 아키텍처 연구개발을 제안·주도했습니다. 전체 연구 기획, 벤치마크 데이터셋, VFM 비교군과 평가 방식을 설계하고 SSL 실험으로 후보 모델들을 개발했습니다. 검증 파이프라인을 기획하고 구현은 팀원에게 맡기면서 전체 연구 방향과 진행을 리드했습니다.

05 · 통찰을 다음 개발의 기반으로

딥바이오에서 파운데이션 모델·VLM·MLLM 조사와 PoC를 수행하며 방법론, 벤치마크, 학습 비용을 검토한 경험을 연결했습니다. 코넥티브에서는 이를 데이터셋 표준화, Task 간 개발 효율화와 멀티모달 확장의 근거로 활용했습니다. AI 도구를 활용해 더 많은 대안을 실험하고 기술 기여를 논리적으로 정리해 MICCAI 2026 논문 성과로 연결했으며, 주저자 논문은 Early Accept를 받았습니다.
